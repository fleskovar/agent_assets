## When to change this case (optional but recommended)

- **A red run is a regression until proven otherwise.** Do not regenerate the
  baseline to get green.
- **The requirement genuinely changed:** add a new case for the new behaviour;
  only edit these files when the old behaviour is retired outright, and say so in
  the commit.
- **Regenerating** (`UPDATE_BASELINES=1 make test-case CASE=<case-name>`) produces
  a diff a human reads line by line, in a commit that changes baselines and
  nothing else.
